# Paolium Pomodoro

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

![Paolium Pomodoro](https://github.com/Paolium/.github/blob/main/logos/paolium-logo-large-tools.png?raw=true)

Enfócate sin salir de tu editor. Sesiones a tu medida, alertas de sonido, temporizador en la barra de estado y notas adhesivas para no perder ninguna idea.

## Funciones

- Sesiones de enfoque personalizables (de 1 a 60 minutos)
- Temas de fondo
- Alertas de sonido al cambiar de fase
- Integración con la barra de estado
- Lienzo libre de notas adhesivas, independiente de cualquier sesión: arrastra, cambia el tamaño y el color de cada nota
- Papelera de notas con 30 días de retención y opción de restaurar

## Comandos

Presiona `CTRL + SHIFT + P` para abrir la paleta de comandos y busca:

- `Pomodoro: Open` - Abre el panel del temporizador
- `Pomodoro: Close` - Termina el temporizador

## Configuración

| Ajuste                      | Valor por defecto | Descripción                     |
| --------------------------- | ----------------- | ------------------------------- |
| `pomodoro.focusDuration`    | 25                | Duración del enfoque en minutos |
| `pomodoro.breakDuration`    | 5                 | Duración del descanso en minutos |
| `pomodoro.roundsPerSession` | 2                 | Número de rondas por sesión     |
| `pomodoro.backgroundImage`  | aurora            | Tema de fondo                   |
| `pomodoro.enableSounds`     | true              | Activa las alertas de sonido    |
